# Native content parity, not pixel parity

The source of truth for what must be preserved is the current working tree, including the Electron renderer, settings, preload contracts, and Tauri-side source where it documents existing behavior. Acceptance is Native Content Parity: the same text, data, state transitions, shortcuts, and interaction outcomes. Exact pixel matching is explicitly out of scope, so the native renderer may choose native typography and layout as long as meaning and behavior are preserved.
